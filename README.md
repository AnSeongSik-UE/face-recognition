# face-recognition

기간: 2023.06 ~ 2023.08

웹캠 영상에서 얼굴과 표정을 인식하고, 인식 상태에 따라 안내 이미지, 배너, 촬영 효과를 합성하는 Python 프로그램입니다.

## 처리 흐름

`웹캠 프레임 입력 → OpenCV/MediaPipe 얼굴/표정 처리 → 상태별 이미지, 배너, 페이드 합성 → 화면 출력`

## 기술

- Python
- OpenCV, MediaPipe, NumPy
- QThread, SQLite, pygame
- Qt Designer

## 개인 기여

- 촬영 전후 상태 이미지를 화면 흐름에 적용했습니다.
- 얼굴 인식 상태에 맞춰 안내 이미지가 나타나고 사라지는 페이드 시점과 투명도를 조정했습니다.
- 촬영 효과와 소리 재생 스레드를 적용하고 연속 촬영이 발생하는 오류를 수정했습니다.
- 하단 배너의 투명도를 조정하고 Windows 응용 프로그램 빌드 설정에 SQLite 의존성을 추가했습니다.

## 협업 범위

얼굴과 표정 인식의 기본 흐름, 설정 화면과 미디어 재생 등은 KAKIS 팀이 함께 개발했습니다.
